시그널방 도우미 (signal-room-bot) 사용 안내
========================================

준비 (처음 한 번만)

1) 텔레그램 API 발급
   - https://my.telegram.org 접속 → 본인 텔레그램 번호로 로그인
   - API development tools → 앱 이름 아무거나 적고 생성
   - 화면에 나오는 api_id 와 api_hash 를 프로그램의 [계정 설정] 탭에 넣고 [저장]

2) 계정 로그인
   - [계정 설정] → [＋ 전화번호로 계정 추가]
   - 전화번호를 국가번호까지 넣고(예: +821012345678) [인증코드 받기]
   - 텔레그램 앱으로 온 숫자 코드를 넣고 [확인]
   - 2단계 비밀번호를 걸어두신 계정이면 비밀번호까지 넣으면 끝입니다
   - 쓰실 계정 수만큼 반복하시면 됩니다 (20개 이상도 됩니다)
   - 로그인 정보는 이 PC 안에만 저장됩니다

3) 방 지정
   - [메인] 탭 → [방 선택] → 시그널 올리실 방을 고르세요
   - [계정 확인] 을 누르면 방에 안 들어가 있는 계정을 알려드립니다

쓰는 법

- [메인] 탭의 큰 버튼(핫키)을 누르면 그 버튼에 넣어둔 문구가
  여러 계정에서 시간차를 두고 하나씩 올라갑니다.
- 오른쪽 [진행 상황] 에 누가 무엇을 올렸는지 실시간으로 보입니다.
  중간에 멈추시려면 [중지] 를 누르세요.
- 청산(수익인증) 버튼은 누르면 이번 시그널의 진입가/청산가를 물어봅니다.
  계정마다 랏과 수익금이 다른 카드가 자동으로 만들어져 함께 올라갑니다.
- 급하게 한 줄만 올리실 땐 아래 [선택 계정으로 한 마디] 를 쓰세요.

버튼(핫키) 고치기

- [핫키 설정] 탭에서 버튼을 추가/복사/삭제하고 순서도 바꿀 수 있습니다.
- 버튼마다 문구를 여러 개 넣어두면 계정마다 무작위로 하나씩 골라 올립니다.
  (한 번에 같은 문구가 두 번 나오지 않습니다)
- 사진을 넣어두면 사진도 무작위로 한 장씩 골라 올립니다.
  보내는 방식을 [사진 + 글] 로 두시면 됩니다.
- 인원(몇 명이 올릴지), 글 사이 간격, 전체 걸리는 시간도 버튼마다 정할 수 있습니다.

참고

- 프로그램이 켜져 있으면 새 버전이 나왔을 때 알아서 최신으로 바뀝니다.
- 텔레그램이 일시적으로 전송을 막으면(FloodWait) 그 계정만 잠시 쉬었다
  다시 시도하고, 나머지 계정은 계속 올라갑니다.
